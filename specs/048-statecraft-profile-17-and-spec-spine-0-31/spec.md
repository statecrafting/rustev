# 048: Statecraft profile revision 17 and spec-spine 0.31.0

## 1. Purpose

The owner directed on 2026-10-21 that Rustev move to spec-spine 0.31.0 and
the newest Statecraft setup profile. This spec records that migration
consent. It amends spec 018's revision 14 binding without rewriting that
approved history. No Rustev product behavior or acceptance authority is
added.

## 2. Territory

This amendment owns no product code and grants no implementation claim.
It changes the adopted setup-profile revision and the engine pin only.
Existing owning specs, workspace boundaries and verifier acceptance remain
unchanged.

## 3. Migration contract

Regenerate the managed setup artifacts with the Statecraft
github-actions-rust revision 17 producer, and move the exact spec-spine pin
from `=0.28.0` to `=0.31.0` through the profile's consented pin move
(revision 15): one reviewed `init plan --spine =0.31.0` and its matching
`init apply --plan <identity>`, judged by an exact 0.31.0 binary. The
registry and index are regenerated by that judge in the same change.

Rustev keeps the ordinary Rust code gate, not the externally supplied code
lane. Preserve the recorded setup parameters and the required reusable
boundaries and verify jobs, all aggregated by the required `ci-gate`.
Revision 16's remote desired-state document is committed as rendered.
Revision 17's AI review reads the default governance documents at the base;
no `review.context_paths` are added. Managed files are produced through
reviewed plan and apply, never hand-edited.

## 4. Acceptance criteria

- The committed managed profile declares revision 17 and agrees with the
  recorded renderer identity.
- `spec-spine.toml` pins exactly `=0.31.0`, and `make gate` passes with
  that binary installed by `make tools`.
- The ordinary Rust code job remains required with the boundaries and
  verify jobs, and `make code` passes.
- No unrelated product code, trust root, secret value, spec lifecycle or
  branch-protection rule is changed by the rendered migration.

## 5. Approval basis

Owner consent is the owner's 2026-10-21 instruction to bring the repository
to spec-spine 0.31.0 and the newest Statecraft profile. The migration PR
changes the authority set and so also needs the owner's approval of the
`statecraft-review-exception` Environment once.
